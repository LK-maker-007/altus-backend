# WHY these exact versions:
#   django-stubs and mypy are tightly coupled — they use internal mypy APIs that
#   change between releases. The django-stubs compatibility matrix (README.md)
#   lists which mypy versions each django-stubs release supports.
#
#   django-stubs 6.0.x → compatible with mypy 1.13–1.20 (official matrix).
#   djangorestframework-stubs 3.16.x → compatible with django-stubs 6.0.x.
#
#   CRITICAL: After any upgrade to mypy or django-stubs, you MUST delete
#   .mypy_cache/ before the next run. A cache built by an older mypy version
#   causes "INTERNAL ERROR — Error constructing plugin instance of
#   NewSemanalDjangoPlugin" because mypy 1.20 cannot deserialize 1.14 cache
#   files. This is the documented root cause of the intermittent crash.
#   Fix: `rm -rf .mypy_cache && mypy ...`
#
#   Source: github.com/typeddjango/django-stubs — Version compatibility section.
